Read the exact versioned docs at https://docs.expo.dev/versions/v55.0.0/ (Expo SDK 55 — pinned because it is the newest SDK supporting Xcode 26.2; SDK 56+ needs Xcode 26.4+) before writing any code.

Code Principles: We value these in order (top most imporant, and so on)
0. Code works
1. Code is simple, easy to understand and maintain
2. Code follows SOLID architecture principles, using Typescript to keep things clean and adhere to architecture principles.
3. Code is easy to test, allowing for dependency injection and testable without a device when possible

Native projects: `ios/` and `android/` are generated by `npm run prebuild` (Continuous Native Generation, see architecture/DECISIONS.md ADR-013) and are gitignored. Never edit them directly — change `app.config.ts` or add a config plugin under `plugins/`, then re-run `npm run prebuild`. Run the app with `npm run ios` / `npm run android` (development build, not Expo Go). Use `npm run doctor` after dependency changes.
